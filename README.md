# 🤖 AI Chatbot using Machine Learning

This project implements an intelligent AI-based chatbot using Natural Language Processing (NLP) and supervised Machine Learning techniques.

The chatbot uses TF-IDF vectorization for text feature extraction and Logistic Regression for intent classification. It predicts user intent based on input text and responds intelligently with confidence scoring.

## 🚀 Features
- Intent classification using ML
- TF-IDF feature extraction
- Confidence score prediction
- Interactive conversation loop
- Expandable training dataset

## 🛠 Technologies Used
- Python
- Scikit-learn
- NLP (TF-IDF)
- Logistic Regression

## 📌 How It Works
1. User input is converted into numerical vectors using TF-IDF.
2. Logistic Regression model predicts the intent.
3. The chatbot returns a response based on predicted intent.
4. Confidence score ensures reliable responses.
